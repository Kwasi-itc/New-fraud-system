## Verified execution path

[Source entry point](../../../backend/data-model-service/internal/service/table_service.go#L151). Table/field endpoints enter owner services, authorize the tenant, then combine metadata changes, tenant DDL and contract/display behavior. Index worker and reconcile executable also mutate physical objects. SQL ingestion contracts and display readers are consumers, not separate databases. Full source occurrences are in the [audit catalog](../../11_source_evidence_catalog.md).

## Target implementation

Use P-01 for table/field/enum/index/archive changes, not only CREATE TABLE. Keep fixed physical mappings, published model version and display version. All six field types (boolean, integer, float, string, timestamp, IP) need parity. Distinguish current metadata nullable/enum validation from actual physical enforcement; do not claim the current DDL already enforces every metadata rule. Runtime table existence checks become full shape inspection. Index jobs must remain recoverable if queue acknowledgement is lost.

Use the common [schema contract](../04_schema_and_data_access_design.md), [security requirements](../05_security_and_integrity_requirements.md) and [transaction protocols](../07_transaction_and_recovery_protocols.md). These are required acceptance inputs, not already implemented helpers.
